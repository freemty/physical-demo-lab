# 双臂任务：参与证据与松手后的持续支撑

2026-09-06，[积木桥报告](../../../reports/demo004-dual-blocks.md)。

本次复用了此前验证的摩擦抓取和世界坐标末端 IK，首轮即完成三个零件的搬运与搭桥。
新的验证要求不在于多放一只机器人，而是明确协作语义：

- 两臂各自的世界位姿和关节需要逐步记录。模型中存在两只手臂，不等于两臂都参与。
  本次从闭爪、手靠近零件和零件相对初态上升 >80 mm 的同时发生重新确定参与者。
- 顺序工作区互斥是有效的基础版协调，但不应叫同时双臂操作或双臂共同持物。
  闲置臂撤到外侧的固定停靠位，中央空间只给当前工作臂。
- 结构在某一帧看似搭好不足够。本次最后演化四秒，独立检查后三秒每帧的高度、
  覆盖、姿态、速度与双爪释放，避免夹爪仍承托或结构即将倾倒却判成功。
- 几何支撑与持续稳定不等于测到接触载荷；未启用接触力读数就不报告力值。

这套证据组织可复用到后续积木/装配任务；实际连接、卡扣或螺纹仍须单独建模和验证，
不能用“堆稳了”代替“插扣连接完成”。
