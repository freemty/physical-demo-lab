# 城堡最小可复现入口的边界

2026-09-06。依据 [Quickstart 验证报告](../../../reports/castle-quickstart.md)
及本仓库 `scripts/castle.py`、`castle_blender.py`、`castle_export.py`。

## 单一蓝图，不暗示任意 Blender 导入

Blender 构建器读取固定 20 件 JSON，生成三个设计视图并输出相同字节的 JSON；
Isaac 读取这份 JSON 编译原生 USD/PhysX。重新打开保存的 Blender 文件检查数量、
位置、几何尺寸和标签，不把能打开文件当作物理通过。

当前入口检查已验收蓝图哈希。任意修改应另建规格、控制器适配与物理验收，
不能只改 `--parts` 或刷新完成指纹。Blender 手工编辑不会自动导回 JSON。

## 导出的是实测轨迹的视图

阶段端点来自完整 60 Hz 控制记录；`:converge` 归并到原阶段。
目标和测量分别保存，单位由具体自由度决定：前七个 Panda 关节是弧度，
后两个手指关节是米。不能把九维数组全称为关节角。

导出成功仅证明格式、连续性和来源检查通过，不代表独立物理成功；
失败轨迹也可导出诊断。原生 240 Hz 接触证据和完整控制日志不删除。

## 入口检查不能替代完整验收

`doctor` 不启动 Isaac，也不证明空闲 GPU、资产联网或任务成功。
Blender 需传 `--python-exit-code 1`，并检查真实输出回执；
不能只信进程 0。严格 `audit` 同时要求原生回放、完整装配与全视频解码，
故散放/预摆模式会失败，不能以其物理稳定冒充机器人搭建。

可移植安装器只处理新建的专属环境；已有 venv 不自动升级。
本轮复用现有项目环境，不宣称第二台机器的全新安装已验证。

## 本轮实际验证与测试环境

新入口完整 20/20 运行经原生回放及整段视频解码通过；另在干净克隆生成场景并做散放试跑。
这些使用同一现有运行环境，不能升级为第二台机器冷安装成功。
仓库控制器单元测试需要 NumPy；本轮系统 Python 缺少它，切换项目 venv 后 65 项通过。
指南要求先激活该环境，不为运行测试往系统 Python 安装依赖。
