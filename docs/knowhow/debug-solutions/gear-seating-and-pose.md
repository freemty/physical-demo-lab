# 齿轮：插入失败要同时检查夹持姿态与碰撞几何

2026-09-06，[demo003 账本](../../../reports/demo003-gears.md)。

首轮抓起、搬运成功，但释放后零件高出底座约 11.8 mm。轨迹显示倾斜主要在插入阶段出现；
“夹爪保持向下”不等于“被夹零件保持竖直”。零件可能在接触中发生相对滑转。

本次检查还发现确定的几何干涉：原中心距 80 mm 小于一轮齿顶半径 43.5 mm
与邻轮齿根半径 37 mm 之和。单纯增加控制时间不能消除这种几何冲突。
程序化复合形状的 USD 变换顺序还应保持平移、旋转、缩放，避免非等比缩放与旋转组合
意外改变齿的预期形状。尺寸应从实际生成代码计算，不能只看封面或最终渲染。

实施了两组联合改动：中心距增加到 81.5 mm、矩形近似齿宽减少到 3 mm；
在 align/insert 阶段从实际零件位姿反馈修正末端平移和完整四元数姿态。
最终 seed 0 的第三次运行达到原先声明的全部物理条件，返回 0；两组修改没有独立消融，
所以只能说该组合在本次场景有效，不能声称证明了每一项修改的单独效果。

姿态计算最初返回 NumPy float32 列表，导致第二次运行在写轨迹时异常。
任务控制器把命令转换成 Python float 后第三次完成，未修改共享记录器。
源码快照、外部进程返回码、异常文件与失败轨迹必须保留；运行时异常不能算物理失败率样本。

这是具有毫米级间隙的教学插装，不推导真实渐开线齿轮、力控搜索、受载传动或视觉泛化。
