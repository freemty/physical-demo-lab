# demo002：超市收银基础版

2026-09-06，运行前定义。参考范围：此前取得的收银台封面（机械臂、传送带、扫描器、屏幕），
没有完整动作轨迹。目标是同类可执行任务，不是原视频逐动作复刻。

- 一个 Franka，从接触驱动的传送带逐个抓取三个商品，经扫描区后放入装袋箱。
- 观测为模拟器提供的位姿和商品 ID；控制为脚本状态机、差分 IK、平行夹爪摩擦。
  不修改商品位置，不附着商品；不使用视觉条码识别、真实收款或学习策略。
- 三个 SKU，价格为整数分；扫描器只在商品中心实际位于空间扫描区且保持足够帧数时记账。
  同一商品只记一次，输出 receipt.json。该检测是显式模拟传感器，不是图像识别。
- 初态随机化：商品尺寸 4.4–5 cm、质量 35–65 g、初始 x/y；每次独立进程。
- 物理成功：每个物体曾由带面搬运 >5 cm、提起 >8 cm；最终完整进入装袋箱并稳定，夹爪已释放撤离。
  业务成功：三个不同 SKU 恰各扫描一次，金额等于商品清单，未扫物体不能直接算完成。
- 负向用例：未扫描、重复记账、金额错误、未释放或未抬起均失败；一步预算应返回非零。
- 初测单 seed 保留视频，修复后至少 3 个独立 seed 检查；若发现接触不稳则扩大检查并保留全部重跑。
  每次上限 8,000 个控制物理步。不得为消除失败放松已声明的物理/扫描条件。
- 中间产物全部位于 Data1 的本项目运行根目录；源码和证据快照、控制轨迹、失败、视频、返回码均保留。
