# demo009：MuJoCo 城堡迁移到 Isaac Sim

用户于 2026-09-06 要求把本任务中已有的物理实验迁移到已配置的 Isaac Sim，先做搭积木。
本项不是 demo004 三件桥的重复，也不声称复刻小红书完整视频。

来源：`assets/block_castle/scene_spec.json` 是原先 20 件城堡 design-v6 的逐字快照。
保留尺寸、质量、目标、支撑 DAG、±3 mm 初态扰动和 ±0.025 rad yaw 扰动。
重新编译为 USD/PhysX，使用本项目 NVIDIA Franka 资产与接触驱动抓取；不复用 MuJoCo 动作作为成功证据。
碰撞和动力学求解器不同，图像外观也不要求像素一致。

## 门槛

1. 独立 goal 模式只验证结构在重力下稳定；不算机器人搭建成功。
2. loose 模式验证初态未解决、落桌稳定；所有动态块均自由刚体，无粘接、焊接、吸附或运行中重置。
3. assemble 模式由机器人依次抓取 20 块，位置 XY <9 mm、Z <6 mm，竖直夹角 <0.07 rad，矩形 yaw 等价误差 <0.1 rad。
4. 每个声明支撑对必须有实际接触，分离距离 <=0.5 mm；末态无机械臂接触，组合线/角速度范数 <0.035；连续满足至少 3 s。
5. 输出每步状态、指令、接触明细、事件、源代码快照/哈希、USD、完整视频、独立进程退出码和审计。失败保留在新目录。
6. 先实现一条完整轨迹，再做固定版本 seeds 0–5；至少 5/6 成功且至少三个完整成功视频，之后才能声称本项验收通过。

边界：特权状态脚本、单一设计的小扰动，不是视觉策略、学习策略、真实机器人或跨引擎逐状态等价证明。
全部实验的迁移依次推进；本项之外尚未迁移的任务不能标为完成。
