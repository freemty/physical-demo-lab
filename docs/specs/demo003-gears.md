# demo003：齿轮插轴与几何啮合

2026-09-06，运行前定义。参考封面为夹爪装配带中心孔的相邻齿轮，未取得完整视频。
本项目实现程序化近似直齿轮的接触装配基础版，不声称复用原作者模型或获得精密工业插装策略。

- Franka 通过实际摩擦夹住齿轮的凸起轮毂，将其从桌面提起、对准竖直轴，插入并释放。
- 齿轮是具有中心孔、轮毂与 20 个实体齿的复合刚体；邻近齿轮与底座固定。
  几何孔洞由局部碰撞形状组成，不以完整实心圆柱伪装成可插轴齿轮。
- 已知位姿与安装目标，脚本 + IK；插入前根据所夹零件位姿修正末端目标和偏航。
  不重写零件状态，不附着到夹爪，不在成功时凭空添加连接关节。
- 成功：曾提起 >8 cm；释放后中心距目标 <3 mm，底面接近底座 <3 mm，
  轴向倾斜 <0.10 rad，齿相位误差 <0.06 rad，线/角速度低且夹爪打开撤离。
- 邻齿轮的几何位置与齿相位在规格中固定；本次仅验收插轴后几何啮合，不验证传动效率、
  受载旋转、弹性形变、真实渐开线齿形或视觉感知。
- 初态随机化：拾取 x/y 小扰动、质量 50–80 g；每 seed 独立进程。目标至少 3 个 seed。
- 负向：未提起、悬在轴上、横向偏移、相位不对、未释放，以及一步预算均不得算成功。
  每次上限 5,000 步；不能为通过而事后放宽已声明的几何条件。

首轮后的设计修订：第一版齿顶半径 43.5 mm、邻轮齿根半径 37 mm，但中心距仅 80 mm，
存在 0.5 mm 几何重叠；将中心距改为 81.5 mm，矩形近似齿宽从 5 mm 改为 3 mm，
留出刚体装配间隙，并将偏航对准改为完整姿态反馈。验收阈值不变。
该版本是带明显间隙的近似教学齿轮，不用于推断精密工业齿轮装配能力。
