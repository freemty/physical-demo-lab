# demo004：双臂搭建积木桥

2026-09-06，运行前定义。参考封面显示两只 Franka 与桌面木制几何积木；未取得完整视频。
本次基础版用两个方柱和一根横梁搭建小桥，不声称原作者具体动作或任意结构泛化。

- 两只独立 Franka 共用桌面；左臂放第一根柱，右臂放第二根柱，再由左臂放横梁。
  通过工作区互斥协调，闲置臂退到外侧；不宣称同时双臂持物或手递手。
- 三个动态刚体仅受重力、接触和夹爪摩擦作用，不改写位姿、不添加隐藏固定连接。
- 输入是已知刚体位姿和目标结构；脚本 IK 控制，不是视觉或学习策略。
- 两柱 60 mm 立方体，中心距 160 mm；横梁 260×55×45 mm，最终必须同时覆盖两柱。
  成功还要求每件曾提起 >80 mm、两只手臂均有在近手闭爪条件下搬运的轨迹证据，
  三件中心距离目标 <12 mm、柱与梁高度误差 <8 mm、倾斜 <0.10 rad、
  横梁偏航误差 <0.12 rad、低线/角速度、双爪打开撤离，并保持至少三秒终态物理演化。
- 初态随机化：各拾取点 x/y ±10 mm，质量扰动；三个独立 seed，一步预算负向用例。
  上限 7,000 步；横梁悬空、缺柱、仅一臂参与、未提起或未释放不得成功。
- 支撑验证结合几何覆盖、高度和终态稳定性；本次不启用接触力传感器，不能声称测到具体载荷。
