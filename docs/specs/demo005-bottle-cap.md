# demo005：灵巧手旋开瓶盖

2026-09-06，资产集成阶段的预先范围。原封面有两只机械臂和拟人手、瓶身及瓶盖，
但没有完整动作视频或源代码。本项目先做夹具固定瓶身、Allegro 多关节手拧盖的基础版；
与封面的双臂拟人手系统不同，不声称原作者实现。

- 使用 NVIDIA 提供的 Wonik Allegro 16 自由度手资产，控制真实关节驱动和指尖接触。
  腕部由显式安装关节驱动；不用直接旋转或提起瓶盖的位姿赋值。
- 瓶身在夹具中固定。瓶盖是有内腔的动态刚体，避免实心盖与瓶颈初始相互穿透。
- 螺纹计划采用公开写明的等效旋转—平移耦合约束，不是微观螺旋齿面接触。
  手指必须通过接触带动实际盖角度，升高必须符合约定螺距；达到预定义旋出圈数后解除
  螺纹约束，继续由手提离瓶口。不得按控制器时间直接宣布旋开。
- 首先运行 `hand_probe.py` 只核对关节、开合、坐标和镜头。该探针成功不算拧瓶盖完成。
  实际螺距、圈数、质量范围和几何验收阈值在第一轮完整任务运行前确定并记录。
- 最终目标至少三个独立初态，以及不闭合手指/步数不足等负向用例；手部运动与
  瓶盖运动须分开审计，保留接触/耦合/脱扣事件及进程状态。

资产依据：[官方机器人目录](https://docs.isaacsim.omniverse.nvidia.com/6.0.0/assets/usd_assets_robots.html)
的 AllegroHand 条目；模型选择与当前本地 SDK 对照，不以存在资产推断任务已实现。
约束依据：[Omni Physics joints](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/rigid_bodies_articulations/joints.html)
的关节和旋转—平移耦合接口；是否适用于本任务仍需要真实运行验证。
